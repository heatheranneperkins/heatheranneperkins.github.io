# Heather Perkins — Product design portfolio

A static, responsive portfolio website. No build tools, accounts or paid services required.

## Preview in Cursor
Open this folder in Cursor. Open `index.html` in a browser, or run `python3 -m http.server 8000` from this folder and visit http://localhost:8000.

## Publish free on GitHub Pages
1. Create a GitHub account if you do not have one.
2. Create a **public** repository named `YOURUSERNAME.github.io` (replace YOURUSERNAME with your actual GitHub username).
3. Upload the contents of this folder to the **root** of the repository, not a nested folder.
4. Under Settings → Pages, select Deploy from a branch, `main`, root `/`.
5. Visit `https://YOURUSERNAME.github.io` once deployment completes.

## Before publishing
- Review every screenshot for confidential information. The owner has confirmed these use demo data.
- Read the case-study copy and confirm it reflects your precise contribution and outcomes.
- The Vantage mobile observation app is discussed but app screenshots are not yet included. Add them when available.
- If desired, replace the Google Fonts import with locally installed/system fonts for fully offline use.
